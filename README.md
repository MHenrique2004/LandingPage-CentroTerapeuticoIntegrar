# 💙 Centro Terapêutico Integrar - Landing Page

Bem-vindo ao repositório da Landing Page do **Centro Terapêutico Integrar (CTI)**! 

Este projeto foi desenvolvido para ser a vitrine digital da clínica, transmitindo acolhimento, profissionalismo e confiança para famílias que buscam desenvolvimento infantil e empoderamento parental. A interface foi pensada para ser limpa, rápida e totalmente responsiva.

## ✨ Destaques do Projeto
*   **Design Responsivo:** Layout adaptável para proporcionar a melhor experiência tanto no celular quanto no computador.
*   **Performance:** Arquitetura leve e rápida garantindo um carregamento suave das imagens e elementos visuais.
*   **Foco no Usuário (UI/UX):** Estrutura de escaneabilidade em "Z" e "F", facilitando a leitura sobre especialidades, corpo clínico e contato.

## 🚀 Tecnologias Utilizadas
Este projeto foi construído com as melhores e mais modernas ferramentas do ecossistema front-end:
*   **React:** Biblioteca para construção da interface baseada em componentes.
*   **Vite:** Ferramenta de build super rápida.
*   **TypeScript:** Trazendo segurança, tipagem e previsibilidade para o código.
*   **Tailwind CSS:** Para uma estilização utilitária, flexível e direto no código.
*   **Lucide React:** Ícones modernos e consistentes.
